# HTML Roguelike Maps

A JavaScript roguelike game built with React and HTML5 Canvas, featuring procedural map generation and classic roguelike gameplay mechanics.

## Features

- Procedural map generation
- HTML5 Canvas rendering
- Classic roguelike controls and gameplay
- Field of view (FOV) system
- Message logging system
- Entity-based architecture

## Quick Start

```bash
npm install
npm start
```

The game will open in your browser at `http://localhost:3000`.

## Built With

- React 16.12.0
- HTML5 Canvas
- ROT.js for procedural generation
- Webpack (via Create React App)
